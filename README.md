# Online-voting-system-
The Online Voting System is a Java-based application developed using Core Java and Object-Oriented Programming (OOP) concepts. It provides a secure and user-friendly platform for voter registration, candidate management, and online voting.It demonstrates key OOP principles such as classes, objects, inheritance, encapsulation, and polymorphism
